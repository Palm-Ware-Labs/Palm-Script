# Palm-Script

Palm-Script is a currently experimental Roblox script, features below.

- Fly
- Noclip
- Invincibility
- Teleport
- Fling
- Spectate
- ESP
- Fullbright
- Jump & Walkspeed Modifiers

## Start
Use any preferred executor and paste this.
```
loadstring(game:HttpGet("https://raw.githubusercontent.com/Palm-Ware-Labs/Palm-Script/refs/heads/main/script.lua"))()
```
